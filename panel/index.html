01 / CONEXÃO COM O BANCO

Banco indisponível

Para o PostgreSQL da demo. O Java continua ativo, mas consultar a saúde ou cadastrar uma pessoa retorna HTTP 503.

A IA deve identificar o banco parado, executar a recuperação e verificar um novo cadastro.
02 / ERRO DA APLICAÇÃO

Falha de validação

Um cadastro válido passa a retornar HTTP 500, com identificação da requisição. O banco e o processo Java continuam ativos.

A IA deve reproduzir o erro e coletar evidências para desenvolvimento. Não é um incidente resolvido por restart.
03 / MEMÓRIA DA JVM

OutOfMemoryError

Esgota os 96 MiB de heap do processo Java e encerra a aplicação. Este painel continua acessível para acompanhar a recuperação.

Gatilho de execução única. A IA coleta os logs e reinicia o serviço via Ansible; restart é mitigação.
